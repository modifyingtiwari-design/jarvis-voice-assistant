Run your iPhone Shortcuts

Create a shortcut in Apple's Shortcuts app first. It can open an app or combine supported actions such as brightness, volume, a Focus or a flashlight action. Then register its exact name here.

Set up a simple app-opening shortcut
  1. In Shortcuts, create a new shortcut.
  2. Add the Open App action and choose the app.
  3. Name it, for example, JARVIS Camera.
  4. Save that exact name above. You can now prepare it with “Run shortcut JARVIS Camera”.

To do several actions, add them inside that shortcut. iOS decides which permissions and confirmation prompts are needed. JARVIS can request the shortcut but cannot inspect its result.
